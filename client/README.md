# Gatherly Client

React frontend for the Gatherly Community Event Management Platform.

## Technologies
- React 18
- Vite
- React Router
- Firebase Authentication
- React Toastify
- Lucide React

## Setup
1. Run `npm install`.
2. Copy `.env.example` to `.env`.
3. Configure Firebase credentials and `VITE_API_URL`.
4. Run `npm run dev`.

## Production Build
Run `npm run build`.

## Development Server
http://localhost:5173

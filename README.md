# Gatherly - Community Event Management Platform

Gatherly is a community-driven platform where people can discover local events, create activities, and participate in community initiatives.

## Features

- Email and password authentication using Firebase.
- Google sign-in.
- Browse upcoming community events and view event details.
- Create events with future dates.
- Update and delete your own events.
- Join events and view joined events.
- Protected routes for authenticated users.
- Responsive design for mobile, tablet, and desktop.
- Toast notifications.

## Technologies Used

- React and Vite
- React Router
- Firebase Authentication
- Node.js and Express.js
- MongoDB Atlas

## Deployment

- Frontend: Vercel or Netlify.
- Backend: Render.

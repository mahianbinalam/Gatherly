# Gatherly — Community Event Platform

Live URL: Add your deployed client URL here.

A community-driven event management platform for creating, discovering, and joining local social-service events.

## Features
1. Email/password registration and login with Firebase Authentication.
2. Google sign-in.
3. Public upcoming events list and event details.
4. Authenticated users can create events with future dates only.
5. Users can manage, update, and delete only their own events.
6. Authenticated users can join events and view their joined events.
7. Responsive layout for mobile, tablet, and desktop.
8. Toast notifications and protected routes.

## Tech stack
React, Vite, React Router, Firebase Authentication, Node.js, Express, MongoDB Atlas.

See `client/README.md` and `server/README.md`. Configure both `.env` files before starting.
